Completed development results in Copilot

The Historical Preference Prior and Dataset-aware ML Recommender panels now display observed development benchmark evidence before a trained model bundle is installed.

  • 47 development datasets, 1,175 completed runs and five seeds: 42–46.
  • Expandable dataset selector with five framework mean ± sample SD tables: accuracy, macro-F1, runtime, peak RSS, energy and CO₂.
  • Download all 235 dataset–framework numeric summaries as CSV. Accuracy/F1 are fractions, runtime seconds, memory MiB, energy kWh and CO₂ kg in the CSV. Screen display uses percentages, Wh and grams.
  • ChaCha-OVR remains a supplementary classification adaptation. The benchmark snapshot includes the full five-framework campaign; the primary trained model can still use four frameworks.
  • Dataset-aware ranking and the current historical prior continue to require an installed validated prefix-only model bundle. Benchmark completeness does not establish recommender validation.
  • No HPC job status, LODO score, external evaluation result or trained-model readiness is fabricated.

Evidence file

artifacts/recommender_v3/development_benchmark.json is a compact snapshot derived from the supplied 1,175-result export. It contains the seed metrics and source/campaign hashes. Every load validates a checksum, complete dataset/framework/seed coverage, task uniqueness, development-only rows, eligibility, consistent sample lengths and finite in-range metrics. It does not load executable model files.

The optional environment variable AWAREML_V3_DEVELOPMENT_RESULTS selects a different snapshot. To rebuild, run python scripts/export_development_dashboard.py --source PATH_TO_EXPORT.json.

Validation

Twelve standard-library unit tests passed. A Streamlit API smoke check confirmed the 47/1,175/five cards, five-row dataset table and 235-row CSV download while model readiness remains unchanged. Python syntax compilation passed. A real browser screenshot test was not performed in this environment.

Scope

The update changes the dashboard renderer and adds an independent evidence reader, exporter, test file and snapshot. All 27 frozen campaign code files were checked against the campaign hashes and remain unchanged. No frozen study files or current HPC results are changed. Model and evaluation bundles must still be transferred from HPC and installed separately once ready.
